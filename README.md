# Matrix Agent Hub

Local-first research and agent orchestration hub for Mikis13 AI.

## Repository policy

- Development work belongs on feature branches.
- No merge, release, deployment, or production publication without separate explicit approval.
- External repositories are catalogued with upstream links, license status, maintenance status, and intended use before any code is copied.
- Third-party source code is not copied wholesale by default. Respect each upstream license and preserve attribution and notices.
- Experiments run in isolated sandboxes. Read-only by default; destructive, network-exposed, paid, or security-sensitive actions require separate approval.

## Source repository catalogue

Numbered records live under `research/repos/` (REPO-0001, REPO-0002, ...). Each record should identify the upstream repository, purpose, license verification, maintenance signals, dependencies, security considerations, and integration recommendation.

## Research principles

Research agents may discover, compare, summarize, prototype, and test. Scientific findings remain hypotheses until independently validated. Medical and drug-discovery work is research support only, not diagnosis, prescribing, dosing, or clinical approval.
